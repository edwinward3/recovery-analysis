# Registry Trust data check

This runs on the RT computer and does not upload either data file.

## Run

1. [Download the program](https://github.com/edwinward3/recovery-analysis/archive/refs/heads/main.zip) and select **Extract All**.
2. Open the extracted folder and double-click `RUN.bat`.
3. Follow the four prompts and wait for **RUN COMPLETE**.
4. Send Edwin the ZIP file marked **SEND_TO_EDWIN**.

Use the full RT CSV or XLSX, including any satisfaction, cancellation, status-date or snapshot-date fields. Also use the dated Companies House Basic Company Data CSV or ZIP. The program asks for the date of each file.

The computer needs 64-bit Python 3.13 or 3.14 with **Add Python to PATH** selected. The first run downloads the required Python packages.

If the program shows **STOP**, send Edwin the complete message. Do not change the data to work around it.
